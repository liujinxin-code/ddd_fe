# 2026-07-22

## FluentValidation 校验器未生效修复

- **问题**：`UserValidators.cs` 中定义的 `CreateUserCommandValidator` 没有起效，请求不合法参数也能通过。
- **根因**：`ApplicationServiceCollectionExtensions.AddApplication()` 只调用了 `RegisterServicesFromAssembly`(注册 MediatR Handler) 和 `AddOpenBehavior`(注册管道行为)，但没有注册 FluentValidation 的 Validator。`ValidationBehavior` 依赖 DI 注入 `IEnumerable<IValidator<TRequest>>`，由于没注册所以是空集合，`_validators.Any()` 为 false，校验被跳过。
- **修复**：在 `AddApplication()` 中增加 `services.AddValidatorsFromAssembly(asm)`（需要 `FluentValidation.DependencyInjectionExtensions` 包，已引用）。
- **项目架构**：DDD 分层 — 1.Open(API) / 2.Application / 3.Infrastructure / 4.Domain；使用 MediatR + FluentValidation 做命令校验。
